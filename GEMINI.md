# Antigravity Agent Rules

1. **STRICT PERMISSION FOR LIVE/GIT PUSHES**: NEVER run `git commit` or `git push` (or any deployment commands) without explicitly showing the changes in the chat and waiting for the user's explicit approval (e.g., "Sari pannu", "Push pannu", "Live-kku move pannu").
2. **NO UNAPPROVED ACTIONS**: Even if Terminal Command Auto Execution is enabled in settings, you MUST logically pause and ask the user in chat before executing any command that pushes code to a remote server or modifies live data.
3. **REVIEW USER NOTES**: Always double-check the user's specific instructions and notes before taking any action. If there is ambiguity, ask for clarification.
4. **COMMUNICATION**: Clearly explain what you are going to do before doing it, so the user has full transparency and control over your actions.
